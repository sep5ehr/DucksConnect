# داکز کانکت (DucksConnect)

**DucksConnect** یک پنل پروکسی چندکاربره پیشرفته و پرسرعت مبتنی بر Cloudflare Worker (VLESS / Trojan) است که با ترکیب قابلیت‌های مدیریتی قدرتمند و ریتینگ بهینه‌شده، تمامی محدودیت‌های دسترسی به سایت‌ها (مانند `check-host.net` و گوگل) را برطرف کرده است.

## ویژگی‌ها
- **مدیریت چندکاربره**: مجهز به دیتابیس Cloudflare D1 (SQLite) جهت ساخت لینک‌های اشتراک مجزا، مدیریت حجم و تاریخ انقضای کاربران.
- **بهبود مسیریابی و رله پشتیبان**: دارای رله‌ها و پراکسی‌پیش‌فرض جهت عبور از محدودیت‌های IP دیتاسنتر و باز کردن تضمینی تمامی سایت‌ها و سرویس‌ها.
- **ربات تلگرام**: قابلیت مدیریت کامل کاربران، آمار مصرف و تنظیمات از طریق ربات تلگرام.
- **حالت مخفی و امنیتی (Stealth & Kill Switch)**: امکانات پیشرفته برای پایداری اتصال.

## آموزش نصب و راه‌اندازی
1. در پنل Cloudflare یک Worker جدید بسازید.
2. یک دیتابیس Cloudflare D1 به نام `ducks-db` ایجاد و به ورکر متصل کنید.
3. کدهای فایل `ducksconnect.js` را درون ورکر قرار دهید (Deploy کنید).
4. از طریق پنل مدیریتی یا ربات تلگرام، کاربران خود را مدیریت کنید.
